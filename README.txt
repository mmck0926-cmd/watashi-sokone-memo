わたしの底値メモ — 試作版
============================

内容
- 商品名・店名・価格・購入日・メモの記録
- 商品名や店名で検索
- 商品の記録内最安値を表示
- 端末内のブラウザに保存
- JSONバックアップの書き出し・読み込み
- PWA用マニフェスト・アイコン・オフラインキャッシュ

使い方
1. このZIPを解凍します。
2. 含まれるファイル一式をHTTPS対応の静的Webホスティングに配置します（例：GitHub Pages）。
3. 公開されたURLをiPhoneのSafariで開き、「共有」→「ホーム画面に追加」します。
4. 初回の記録は端末内に保存されます。ブラウザデータ消去に備え、定期的に「データ管理」からバックアップを書き出してください。

重要
- これは試作版で、App Storeに公開されたネイティブアプリではありません。
- HTTPSのWebサイトとして公開してからホーム画面に追加する必要があります。
- 現在の保存方式は端末・ブラウザ単位です。別端末との自動同期はありません。
- レシートOCR・バーコード読取は未実装です。
